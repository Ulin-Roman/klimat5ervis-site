## Что изменено

- Оптимизированы изображения, присутствующие на проверенных страницах: WebP, разумные размеры, сохранена анимация GIF. Для 41 сопоставленного URL суммарный объём выбранных исходных ресурсов 4 084 277 → 820 939 байт. Оригиналы сохранены.
- Большое встроенное изображение сертификата вынесено из HTML. Добавлены размеры изображений, alt, асинхронное декодирование и lazy loading для второстепенных изображений; главный баннер и главное изображение товара загружаются приоритетно.
- Шесть небольших файлов оформления выводятся в HTML из исходных CSS-файлов: меньше блокирующих запросов, дальнейшие изменения CSS остаются видимыми. Скрипты подвала используют defer с сохранением порядка. Библиотека jQuery в шапке оставлена синхронной для совместимости со старым кодом.
- Код фильтра ASMP загружается только в каталоге. Из jQuery удалён отдельный добавленный обфусцированный фрагмент, отправлявший имя домена на tmpl24.ru. Сама библиотека сохранена.
- Добавлены canonical с исключением рекламных параметров, Organization/WebSite и Product/Offer. Цена и название берутся из данных карточки; выдуманные оценки и наличие не добавлялись.
- Удалён общий лишний H1 на внутренних страницах. У товара остался один HTML H1; мобильная версия названия сохранена визуально. H1 из описания поставщика понижен до H2.
- Вместо description «Каталог» карточки получают описание с названием товара. Для пагинации title и description содержат номер страницы.
- robots.txt разрешает нужные CSS/JS, указывает Sitemap и Clean-param для Яндекса. Служебные разделы получают noindex.
- В .htaccess добавлены XML Sitemap redirect, кэширование WebP и сжатие HTML/XML.
- Добавлены подписи полей количества товара и основной landmark страницы.
- Рабочий счётчик Яндекс Метрики 106704540 сохранён.

## Что остаётся

Мобильная загрузка ещё нуждается в дальнейшем ускорении: FCP 4,6 с и LCP 5,5 с в Slow 4G. Старые синхронные зависимости шапки, шрифты и уведомление cookie влияют на первый экран. Последний Lighthouse также отмечает контраст, размеры некоторых touch targets, соотношение сторон отдельных изображений, неиспользуемые части библиотек и стили. Их нельзя удалять целиком на основании проверки только трёх типов страниц.

Исходные изображения не удалены без проверки связей в базе HostCMS: они могут использоваться в других товарах, галереях и описаниях. Проверка всех записей каталога, переписывание контента поставщиков и обновление PHP/CMS не выполнялись. В панели хостинга указана PHP 7.4; изменение версии требует отдельной проверки совместимости модулей.
