The original structures and documents are read only. The actual site is **Site 2**; the cart belongs to **Shop 1**, which is a different identifier. Sources accept only their own root route; request parameters cannot select a document. They validate the current route's site, active Site-2 source and finite parent chain, effective public access, and the expected document association/site. Documents have no assumed `active` property.

Structure, ancestor and document models are explicitly loaded with `Core_Entity::factory(...)->find($id)` before checking `loaded()`. This invokes native ORM loading and deleted-record filtering; constructing `factory(..., $id)` alone is lazy and must not be followed by an immediate `loaded()` gate. The fixed source's `document_id` association is checked before loading the expected document. Parent cycles/depth are checked before recursive `getSiteuserGroupId()` calls.

Content comes from the current `Document->text`. It is not copied from the captured public DOM, executed as PHP, passed through `Document::execute()`, or serialized through a DOM parser. This intentionally omits document execution hooks, shortcodes and admin WYSIWYG controls. Check live content for any shortcode-dependent block.

The first native H1 is preserved. If absent, the structure name supplies an outer H1. Subsequent native H1 tag names become H2; their text and attributes stay unchanged. Comments and script/style/textarea/title blocks are excluded from heading processing. No other document content is rewritten.

Header, footer, telephone and messenger widget were copied from the current `modern-home-20261117/ModernHome2026.xsl`. Shared information links point to the new previews. The cart count remains native. Styling is scoped to the information layout and existing contacts/feedback classes; it does not remove inline native colors. The current Contacts XSL also supplies `.info-contact-action .info-form-button`, a normal link to the existing `/kontakty/feedback/` form. It introduces no new form or submission handler. Styling of any existing native feedback CTA targets that exact URL rather than all nested telephone links.

The current four modern XSL files use base blue `#006b89`. After the parent's final replacement, the reviewed files also contain zero remaining literal `#007d9f` references, including inherited `.mh-*` rules. The files contain no literal CSS `>` child combinators, avoiding the observed HostCMS CSS-serialization issue. Messenger brand colors are separate from this base-color change.

`contacts-public-main.html` is the unchanged public capture supplied by the parent agent. It is a QA fixture only: the captured email has already been decoded while its HostCMS decode script remains present. Do not paste that capture into a document.
