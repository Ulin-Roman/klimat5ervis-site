# Живой каталог HostCMS — 16.11.2026

Предпросмотр: https://klimat5ervis.ru/modern-catalog/
Проверка ширин: https://klimat5ervis.ru/modern-catalog/?view=responsive

Это второй этап: отдельный серверный каталог на существующем HostCMS 7.1.7. Он получает актуальные товары и цены через Shop_Controller_Show магазина 1. Статический index.html рядом остаётся прототипом главной страницы с 8 моделями.

## Размещение

- XSL ModernCatalog2026 (ID 390): ModernCatalog2026.xsl.
- Узел структуры ID 68, путь modern-catalog, тип Dynamic page, макет 8 (только Core_Page::instance()->execute()).
- Код узла: structure-source.php; настройки узла: structure-config.php.
- Узел скрыт из меню, индексация отключена; дополнительно meta robots и X-Robots-Tag noindex,nofollow, Cache-Control private,no-store.
- Не загружать эти PHP-файлы как самостоятельные публичные endpoints: это содержимое штатных полей HostCMS.

## Поведение

Выборка по 24 товара, поиск по названию/производителю, диапазон цены и сортировка. Запросы ограничены известными параметрами; значения поиска экранированы для LIKE и передаются через queryBuilder. Список не выгружается целиком в JS. Вывод использует нативные правила магазина и цену price из XML, включая скидку. Ссылки товаров ведут на действующие канонические карточки. В корзину добавляет существующий обработчик /category/cart/; модифицируемые товары направляются в карточку.

Каталог не требует клиентского JavaScript. Изображения имеют размеры и lazy loading. Это ещё не массовая конвертация изображений в WebP/AVIF и не настройка серверного кэша.
