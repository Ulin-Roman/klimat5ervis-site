## Состояние исходников

Полный снимок содержит 30 424 исходных файла: PHP, шаблоны, XSL, CSS, JavaScript и публичные изображения. Размер полного архива: 1 918 088 638 байт. SHA-256:

`a01f134e530069fb2ae072a27a78d97f9bc15474d685894158c68a03b10f4990`

В архиве есть `docs/source-manifest.json`. Пароли, рабочая конфигурация лицензии, пользовательские файлы, журналы, кэш и временные выгрузки исключены. Для основных секретных настроек добавлены примеры.

Полное дерево файлов ещё не развёрнуто в main: исходный снимок и обновление доступны архивами. Автоматическое развёртывание на хостинг не настроено.

## База данных и запуск

База MySQL в публичные архивы не включена. Для запуска копии нужны соответствующая база, PHP, действующая конфигурация HostCMS и приватные настройки. На момент аудита в панели хостинга указана PHP 7.4. Этот проект не является статическим сайтом для GitHub Pages.
