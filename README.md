# Климат-Сервис — klimat5ervis.ru

Открытая копия проекта на HostCMS с хостинга Timeweb.

## Состояние переноса

Файлы действующего сайта скопированы **16 ноября 2026 года** из каталога `public_html` и сохранены в GitHub как архив выпуска. Развёртывание файлов в основную ветку ещё не выполнено.

[Скачать архив исходников и изображений](https://github.com/Ulin-Roman/klimat5ervis-site/releases/tag/snapshot-2026-11-16)

- 30 424 исходных файла: PHP, шаблоны, XSL, CSS, JavaScript и публичные изображения.
- Размер архива: 1 918 088 638 байт.
- В архиве есть `docs/source-manifest.json` с SHA-256 и размером каждого исходного файла, а также перечнем исключений.
- Пароли, рабочая конфигурация лицензии, пользовательские файлы, журналы, кэш и временные выгрузки исключены. Для основных секретных настроек добавлены файлы-примеры.

## База данных и запуск

База MySQL в архив **не включена**. В Timeweb запрошено сохранение резервной копии базы сайта от **14 ноября 2026 года**; завершение этой операции пока не подтверждено. Это отдельная дата от снимка файлов.

Для запуска копии нужны соответствующая база MySQL, PHP, действующая конфигурация HostCMS и приватные настройки. На момент копирования у рабочего сайта в панели указана версия PHP 7.4. Этот проект не является статическим сайтом для GitHub Pages.

Действующий сайт не изменялся. Автоматическое развёртывание на хостинг не настроено.
